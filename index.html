Frequently Asked Questions

Here are some of the frequently asked questions

What is roadmap.sh?

▼
roadmap.sh is a community effort to create learning paths, guides, project ideas and other similar content to help developers grow in their careers.

What are the plans for roadmap.sh?

▼
Our long-term plan is to make roadmap.sh a go-to place for developers wheneever they plan on learning something new.

How is roadmap.sh built?

▼
The website is built with Astro and Tailwind and is deployed to GitHub pages. The project is open-core and the codebase can be found on GitHub.

Can I use roadmap.sh in my team?

▼
No, the license of the content on this website does not allow you to redistribute any of the content on this website anywhere.

How can I create custom roadmaps?

▼
For new roadmaps, please open an issue with the textual description of the roadmap in the form of a bulleted list. Here is an eample contribution of a new roadmap.

Is roadmap.sh really the 6th most starred project on GitHub?

▼
Yes! roadmap.sh currently has over 369,000 GitHub Stars and gaining 90,000 registered users every month!
